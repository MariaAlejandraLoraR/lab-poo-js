1. ¿Qué ventaja técnica tiene crear un molde (función constructora) en lugar de escribir un objeto literal individualmente para cada computador?

La ventaja es que no repito código. Con una función constructora creo un "molde" y luego hago 100 computadores con new sin escribir las propiedades una por una.

this aísla los datos y Cada objeto tiene su propia copia de las propiedades. 

3. ¿Qué ventajas a nivel de cohesión de software presenta que el objeto conozca por sí mismo su estado lógico (si aprobó o no)?

significa que el objeto tiene todo lo que necesita adentro y no depende de código externo.
